# Free AI Tools Directory website

Next.js application for browsing the repository's AI tool catalog and curated stacks. The app uses the Next.js App Router under `src/app/`; local catalog data lives under `src/data/`.

No package lockfile is checked in. Dependency resolution can vary by package manager and install date.

## Package scripts

Run these from the `website/` directory after installing dependencies:

```sh
npm run dev
npm run build
npm run start
npm run lint
```

The scripts are declared in `package.json`. This README audit did not run them.
